# Pre-run sample (classroom fallback)

Frozen **14 September 2026** from published news and official pages. No social media. Quotes are taken from the pages listed in `articles.json`.

If a fact was missing on the page (for example a publish date), the cell is `not found`.

Regenerate the HTML/Markdown/CSV from this JSON:

```bash
python -m montenegro_res_news --sample --write-sample
```

Do not replace this folder with a thin live harvest.
